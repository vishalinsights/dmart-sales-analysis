# DMart Sales Analysis

## 📊 Project Overview

This project analyzes DMart sales data to identify sales trends, customer behavior, product performance, and overall business performance.

## 🎯 Objective

The main objective of this project is to analyze sales data and generate meaningful insights that can help understand:

- Sales performance
- Product performance
- Customer purchasing patterns
- Regional performance
- Revenue trends

## 🛠️ Tools & Technologies

- Microsoft Excel
- Data Cleaning
- Data Analysis
- Pivot Tables
- Charts & Dashboards

## 📁 Dataset

The dataset contains information related to sales transactions, products, customers, quantities, prices, and sales values.

## 🔍 Analysis Performed

- Data cleaning and preprocessing
- Sales and revenue analysis
- Product-wise analysis
- Category-wise analysis
- Customer analysis
- Regional analysis
- KPI calculation
- Dashboard creation

## 📈 Key Insights

The analysis helps identify:

- Top-performing products
- Highest-performing categories
- Sales trends
- Revenue contribution
- Areas with higher/lower performance

## 📊 Dashboard

The project includes an interactive dashboard created using Excel to visualize important KPIs and sales trends.
